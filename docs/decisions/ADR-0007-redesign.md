# ADR-0007 — Quiet visual system

Status: accepted by the executor under the owner's autonomous LINGO-07 brief.

Use SF system fonts via Font.system, Apple's built-in SF Symbols, native SwiftUI/AppKit controls and an original vector Lingo mark. No font files, paid services or third-party dependencies are added. ImageGen is used only through the existing subscription for references and the permitted app icon. Future web concepts map tokens to CSS variables with a system-font fallback; no website is implemented here.

The vector mark, flat surfaces and native control rendering are the reproducible specification when ImageGen invents incompatible strokes, gradients or text geometry. Such differences remain recorded in evidence; this decision does not waive the owner's comparison criteria.
