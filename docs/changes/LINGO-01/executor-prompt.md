Ты — исполнитель проекта Lingo: личное приложение для голосовой разговорной практики английского и немецкого.
В этой задаче делается только MVP для macOS. iPhone — следующая задача LINGO-02. Работаешь без истории прошлых чатов.

## Прочитай перед работой (обязательно, в этом порядке)
1. `CLAUDE.md` и `DESIGN.md` — правила проекта, запреты, Git-политика, дизайн-токены.
2. `README.md` — назначение и структура.
3. `docs/reference/owner-brief.md` — исходное ТЗ владельца. Порядок работ в нём изменён решением Q27: сначала Mac.
4. `docs/changes/LINGO-01/intent.md` — цель, границы, решения Q1–Q27, допущения A-1…A-9.
5. `docs/changes/LINGO-01/spec.md` — требования R-01…R-50, сценарии S-01…S-20, критерии AC-01…AC-16. Единственный источник требований.
   Раздел 4 (F-проверки) — черновик для LINGO-02, в этой задаче не выполняется.
6. `docs/decisions/ADR-0001-stack.md` — стек, разрешённые зависимости.
7. `docs/changes/LINGO-01/plan.md` — шаги P-00…P-12, точки H-0…H-5, проверки, условия остановки.
8. `evals/README.md` и `docs/reference/pdf-patterns.md`.
9. `docs/changes/LINGO-01/handoff.md` — где остановилась прошлая сессия.
10. Фактические `git status` и `git log --oneline -10`. Если они расходятся с handoff.md, верь Git и запиши расхождение.

Кратко (5–10 строк) подтверди: какие версии документов прочитаны, текущий шаг, ближайшая точка H.

## Что сделать
Реализуй plan.md по шагам, начиная с первого незавершённого в handoff.md, до P-12 включительно.
Итог:
- `dist/Lingo.app`, которое владелец запускает на своём Mac и использует для голосовой практики;
- `docs/changes/LINGO-01/report.md` со свидетельствами по AC-01…AC-16;
- ядро `LingoCore`, которое собирается для iOS.

## Как работать
- Один шаг P-xx за раз. После шага:
  1. проверки шага из plan.md;
  2. просмотр своего diff: лишние файлы, секреты, `private/`;
  3. обновление handoff.md;
  4. коммит `P-xx: <что сделано>`;
  5. `scripts/secret-scan.sh`;
  6. `git push origin feat/lingo-01`.
- Не задавай владельцу вопросов, кроме точек H-0…H-5. В точке:
  - остановись;
  - дай пошаговую инструкцию на русском (что нажать и где);
  - укажи, что проверишь после ответа;
  - жди «готово».
- Неоднозначность вне точек решай сам, в таком порядке приоритета:
  1. spec;
  2. DESIGN.md и `docs/design/lingo-mac.webp`;
  3. Apple HIG;
  4. техническая целесообразность.

  Решение записывай в handoff.md → «Решения исполнителя» со ссылкой на номер R- или AC-.
- Факты о внешних системах проверяй по первоисточникам на дату шага, а не по памяти:
  - лимиты и модели Groq, Mistral, OpenRouter;
  - релизы whisper.cpp;
  - модели Hugging Face;
  - Apple Speech.

  ID моделей бери из `GET /models`. Ссылки и даты записывай в handoff.
  Если страницу не удаётся прочитать (блокировка, логин, ошибка), остановись и попроси владельца вставить содержимое. Не восстанавливай по памяти.
- Слой моделей переноси из Interview Copilot (`~/Desktop/InterviewCopilot-redesign/Результат-ImageGen/source`, коммит `cf0e764`)
  копированием с адаптацией по R-29. В шапке файла укажи, откуда он взят.
- `LingoCore` — без AppKit. Сборку для iOS проверяй `scripts/check-core-ios.sh` на каждом шаге, начиная с P-01.
- Числа AC снимай реальными прогонами. Не объявляй готовность по одному запуску интерфейса.

## Границы
- Разрешено:
  - писать код, тесты и скрипты в репозитории;
  - ставить зависимости из ADR-0001 п. 11;
  - скачивать модели whisper с проверкой SHA256;
  - создавать папку `Lingo` в iCloud Drive владельца;
  - коммитить и пушить в `feat/lingo-01`.
- Запрещено:
  - force-push, `reset --hard`, удаление веток, merge в `main`;
  - вводить или выводить Apple ID, пароли и ключи; просить их в чате;
  - создавать аккаунты;
  - менять TCC, Keychain trust и системные настройки;
  - коммитить `private/`, модели, логи, `evals/out/`;
  - любые платные сервисы и провайдеры с обязательной картой;
  - публиковать что-либо;
  - делать iOS-приложение, ставить SideStore, проектировать интерфейс iPhone (всё это — LINGO-02).
- Не ослабляй тесты и пороги evals ради зелёного результата. Не пиши «проверено» без фактического запуска.
- Новая зависимость вне ADR-0001 — только с записью в ADR и пометкой «требует подтверждения владельца».
