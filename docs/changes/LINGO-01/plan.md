## Риски и откат
| Риск | Признак | Действие |
|---|---|---|
| SideStore не поддерживает установленную iOS 27.x | H-1 не проходит | Стоп, G-1 досрочно, варианты из spec, раздел 6 |
| llama.cpp на A13 только на CPU, медленная обработка промпта | `llm_first_token` > 8 с | Кэш обёртки, короче обёртка для локального режима, меньший кандидат; затем spec, раздел 6 |
| Нехватка памяти (jetsam) | MetricKit, флаг падения | Модель меньше, whisper меньше или движок Apple, выгрузка распознавания на время генерации |
| `SpeechTranscriber` недоступен на iPhone 11 | `isAvailable == false` | `SFSpeechRecognizer` или whisper.cpp |
| Смешанная речь плохо распознаётся | F-06 ниже порога | R-09; проверка сегментного распознавания; spec, раздел 6 |
| Эхо на динамике ломает перебивание | F-09 ниже порога | Порог VAD во время озвучки, «только наушники» для перебивания с пометкой в отчёте |
| iCloud не скачивает файлы в чужой папке | F-08: файлы не появляются | `startDownloadingUbiquitousItem`, координированное чтение; spec, раздел 6 |
| Лимиты Groq во время evals | 429 | Пауза, ротация ключей и моделей, растянуть прогон; ключей не просить |
| Нехватка диска | < 3 ГБ свободно | Удалить неиспользуемые модели и DerivedData проекта; ничего чужого не трогать |

Откат: каждый шаг — отдельный коммит в `feat/lingo-01`. Провалившийся шаг откатывается через `git revert` своего коммита. `main` не меняется.
